# Mien - 3D Action Roguelike (Prototype)

Mien is a 3D top-down action roguelike developed as a university team project. The core mechanic revolves around masks: equipping different masks grants the player unique abilities and changes the overall playstyle.

## Overview
* **Gameplay:** Fast-paced top-down action, inspired by *Hades* and *The Binding of Isaac*.
* **Visuals:** Late 90s / early 2000s low-poly PSX aesthetic (inspired by early 3D *Zelda* games, *Silent Hill*, and *Metal Gear Solid*).

## Tech Stack
* Unity 3D
* C#
